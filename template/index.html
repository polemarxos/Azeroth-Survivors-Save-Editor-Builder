Status

Zones cleared per class

Tick the zones each class has cleared. The game’s “unlocked” count is set for you from the furthest zone ticked. Un’Goro Crater, Scarlet Monastery and Naxxramas are new in the latest version.

Heroic difficulty per class

Highest Heroic level beaten in each zone (I to V). Beating a level opens the next one, and lets that class’s gear from the zone go to that many stars. Setting a level also marks the zone as cleared and unlocked on the Zones tab.

Perk levels

Keep levels close to what you already have. A level above the game’s own maximum may be ignored or misbehave.

Races opened to every class

A race ticked here can be picked by every class. Without this record the game only offers each class its usual races.

Talent points come from experience. If you max every talent, also raise the experience a lot, or the game may not count all points as earned.

Talents

Left-click adds a point, right-click removes one, Shift-click fills or empties a talent.

Tap an item to mark it unlocked; unlocked items get a star level (0 to 5) you can change. Max stars only affects gear you have unlocked. Tap a tier button to toggle that tier for every slot, or a slot name to toggle that whole row. Item icons come from Blizzard's item data, which the game doesn't store, so tiles show the slot in the tier's rarity colour.

Pets

Some pets and tabards are rewards for achievements; ticking one of those also grants its achievement.

Tabards

Appearances

Cosmetic looks any class can show. Each is unlocked by an achievement, so ticking one grants that achievement.

Each entry counts as seen at its own rarity. Legendary amulets are one per class spell.

Raw text

This is the whole save as plain text, one record per line (items, equip, talent, seen, ach and so on). Edit anything, then press Apply. The fields on the other tabs update to match.

How to use the edited file

1. In the game open Options → Saves and note the folder it shows. 2. Put the downloaded .sav file in that folder. 3. Pick it in the list and press Import. The game keeps a copy of your old progress as characters.before-import.

Importing replaces all progress with the file’s contents. Keep your original export as a backup.
